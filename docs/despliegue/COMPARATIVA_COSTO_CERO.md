# Alojamiento RSU V4.1

Consulta de fuentes oficiales el 19 de noviembre de 2026. El perfil de evaluación requiere PHP/Laravel, MySQL persistente, almacenamiento de archivos, HTTPS fuera de LAN y un acceso revocable. Los créditos limitados requieren un plan de exportación previo a su vencimiento.

| Alternativa | Encaje y decisión |
| --- | --- |
| PC existente o equipo doméstico dedicado | Compatible con MySQL y PHP ya instalados. Útil para LAN aislada y como origen de una VPN. Requiere energía, control del anfitrión y un enlace entre clientes. Un segundo equipo trasladaría la dependencia de la PC si se migra también MySQL y el almacenamiento. |
| Tailscale Personal y Serve | Hasta seis personas según el plan publicado. Candidato para un grupo académico pequeño si su uso es elegible. Serve permite HTTPS dentro de la red privada. Requiere una cuenta administradora y dispositivos invitados. Depende de que el host siga encendido. [Plan](https://tailscale.com/pricing), [Serve](https://tailscale.com/kb/1312/serve) |
| Cloudflare Tunnel | Quick Tunnel crea una URL temporal, carece de SLA y admite hasta 200 solicitudes simultáneas. Se reserva como prueba con un origen ficticio y control explícito de acceso. El túnel administrado requiere una zona y una política de acceso compatible con los APK. Ambos dependen del origen. [Quick Tunnels](https://developers.cloudflare.com/cloudflare-one/networks/connectors/cloudflare-tunnel/do-more-with-tunnels/trycloudflare/) |
| ngrok Free | Cliente instalado. El plan documenta un dominio de desarrollo y hasta 20 000 solicitudes HTTP mensuales. El origen debe seguir encendido y el titular debe confirmar plan y controles antes de habilitarlo. [Límites](https://ngrok.com/docs/pricing-limits) |
| Oracle Always Free | Ofrece recursos de cómputo candidatos para Laravel y MySQL. El alta exige verificación de pago y la documentación contempla recuperación de instancias inactivas. Excluido bajo las condiciones de esta misión. [Alta](https://www.oracle.com/cloud/free/faq/), [recursos](https://docs.oracle.com/en-us/iaas/Content/FreeTier/freetier_topic-Always_Free_Resources.htm) |
| Google Cloud Free Tier | Compute Engine tiene una cuota gratuita ligada a una cuenta de facturación y a restricciones regionales. Excluido sin proyecto con facturación admitida y un límite verificable. [Free Tier](https://docs.cloud.google.com/free/docs/free-cloud-features) |
| Azure for Students | Candidato condicionado a verificación académica, cuota y crédito educativo de USD 100. Microsoft ofrece el alta sin tarjeta para estudiantes elegibles. Evaluar un despliegue completo en una VM y exportar antes de agotar el crédito. [Azure for Students](https://azure.microsoft.com/en-us/free/students) |
| GitHub Student Developer Pack | El catálogo de beneficios requiere acreditación estudiantil. Cada crédito de terceros tiene condiciones y vencimiento propios. [Catálogo](https://education.github.com/pack) |
| Railway Free | USD 1 mensual de uso, hasta 0,5 GB de volumen para una base y suspensión por inactividad. El conector devolvió un proyecto existente con MySQL y sin Laravel. Falta comprobar el plan efectivo, el saldo y la capacidad de ejecutar ambos servicios. El proyecto no se modificó. [Plan Free](https://docs.railway.com/pricing/free-plan) |
| PHP/MySQL compartido gratuito | InfinityFree documenta una verificación de navegador que restringe clientes automatizados. Queda descartado para la API de los APK. [Restricciones de acceso](https://forum.infinityfree.com/t/browser-security-system-features-and-limitations/49353) |
| Render, Fly.io y AWS | Render no añade disco persistente a servicios web gratuitos. Fly.io ofrece una prueba de dos horas de VM o siete días. AWS tiene un plan nuevo limitado por tiempo y créditos. Estas opciones no acreditan persistencia MySQL a costo cero indefinido para esta cuenta. [Render](https://render.com/docs/free), [Fly.io](https://fly.io/docs/about/free-trial/), [AWS](https://aws.amazon.com/free/free-tier-faqs/) |
| Alojamiento universitario | Alternativa para mantener disponible el sistema con la PC apagada si TI concede un host, almacenamiento persistente, acceso HTTPS y restauración. Sigue pendiente identificar un servicio que la universidad autorice para este proyecto. |
| Android con Termux | Alternativa experimental de LAN en un dispositivo dedicado y autorizado. Android puede terminar procesos en segundo plano. Requiere ensayar persistencia, carga, seguridad y recuperación antes de depender de ella. [Termux](https://github.com/termux/termux-app#readme) |

Decisión actual. Usar el servidor local y MySQL existentes para el laboratorio. Para exposición, ensayar una red propia con un teléfono físico antes de acreditar LAN. Para acceso remoto, priorizar Serve tras confirmar titular, elegibilidad y participantes. La nube independiente queda pendiente de una cuenta estudiantil elegible o un host universitario autorizado. No se creó ningún recurso facturable.
