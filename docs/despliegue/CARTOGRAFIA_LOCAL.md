# Calles locales de Chiclayo

El recorte de demostración contiene 85 vías extraídas el 19 de noviembre de 2026 de un área de 0,006 × 0,006 grados. La app incluye el recorte como dato vectorial y el panel lo sirve desde el mismo origen. La capa es independiente de las teselas de Internet. Fuera del área se conserva la representación de la zona, los puntos y la trayectoria con una etiqueta de ausencia de calles locales.

Los datos proceden de OpenStreetMap contributors bajo ODbL 1.0. El fichero contiene coordenadas redondeadas y conserva la URL de extracción y la atribución. Se realizó una consulta de datos de área pequeña. No se incorporaron teselas ni se configuró precarga.
