# Glosario

| Término | Significado en este proyecto |
|---|---|
| AJAX / fetch | Pedir datos o enviar un formulario sin reemplazar la página entera |
| API / endpoint | Dirección que recibe una solicitud y devuelve información; `/admin/modelos/datos` es un endpoint JSON |
| Artisan | Consola de Laravel; se usa con `php artisan` |
| Asset | Archivo de estilos, JavaScript, fuente o imagen |
| Autenticación | Comprobar quién es una persona mediante su cuenta |
| Autorización / Gate | Decidir si una cuenta puede realizar una acción |
| Blade | Plantillas que Laravel convierte en HTML |
| Caché | Copia guardada para reutilizar una respuesta o archivo |
| Cabecera HTTP | Información que acompaña a la solicitud o respuesta, como Content-Type |
| Componente / partial | Fragmento reutilizable de interfaz; los componentes admiten propiedades y contenido |
| Composer / npm | Herramientas que instalan dependencias PHP / JavaScript |
| Controlador | Código que recibe una solicitud y organiza la respuesta |
| CRUD | Crear, consultar, actualizar y eliminar registros |
| CSRF | Ataque que intenta ejecutar acciones desde otra página usando una sesión ajena; el token protege formularios |
| DataTables | Biblioteca de tablas con búsqueda, orden y páginas |
| Eloquent | Herramienta de Laravel para consultar tablas mediante modelos |
| Factory / fixture | Generador de registros / datos preparados para una prueba |
| HTML / JSON | Formato de una página / formato estructurado de datos |
| Índice / unicidad | Regla SQL para buscar eficientemente / impedir duplicados |
| Middleware | Comprobación que rodea el trabajo del controlador |
| Migración / seeder | Cambio de estructura SQL / carga de registros iniciales |
| Modelo / relación | Representación de una tabla / vínculo entre registros |
| Namespace / autoload | Dirección lógica de una clase / mecanismo que encuentra su archivo |
| N+1 | Repetir una consulta por cada fila en lugar de cargar sus relaciones juntas |
| PHPUnit / prueba de regresión | Herramienta de pruebas PHP / prueba para impedir que vuelva un fallo |
| Responsive | Interfaz que se adapta al espacio de pantalla |
| Ruta / resource | Asociación URL-código / conjunto de rutas CRUD de Laravel |
| Servicio | Código que concentra un proceso o regla de negocio con sentido propio |
| Sesión / cookie | Estado de acceso guardado por el servidor / identificador que conserva el navegador |
| Transacción / concurrencia | Grupo de escrituras que se confirman juntas / operaciones simultáneas |
| Validación / 422 | Comprobación de datos / respuesta que informa que los datos no son aceptables |
| Vary | Cabecera que indica qué partes de la solicitud distinguen las copias de caché |
| Vite | Herramienta que compila los assets de `resources` |
| WCAG / foco | Recomendaciones de accesibilidad / indicador del control que recibe el teclado |
| XSS / escape | Inyectar código en contenido / convertir texto para que no se ejecute como HTML |
