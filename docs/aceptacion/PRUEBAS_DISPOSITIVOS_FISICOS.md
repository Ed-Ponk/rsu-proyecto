# Dispositivos físicos y acceso externo

ADB detectó dos emuladores Android 36. El inventario carece de teléfonos físicos disponibles. Proporcionar un Android autorizado para probar GPS apagado, permisos, pantalla bloqueada y los dos APK. Usar otro cliente para el panel y habilitar una red privada o un hotspot propio. Probar caminando.

Para el ensayo externo, confirmar el titular del acceso VPN o el frontal HTTPS, la elegibilidad de costo cero y un teléfono con otra conexión autorizada. El estado de cada caso figura en la [matriz DEP](../despliegue/RESULTADOS_DEP.csv).
