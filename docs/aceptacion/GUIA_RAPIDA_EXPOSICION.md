# Exposición rápida

1. Confirma APK, firma, perfil y origen contra el manifiesto de la entrega.
2. Verifica MySQL y panel con la [guía de instalación](../despliegue/INSTALACION_LIMPIA.md).
3. Crea una programación y marca asistencia. Desde Conductor inicia el recorrido. Desde Ciudadano sigue el mismo servicio, consulta el estado final y vota.
4. Si falla Internet, aplica el [plan de contingencia](../despliegue/GUIA_EMERGENCIA_EXPOSICION.md). Identifica las capturas previas y el GPS simulado al pasar a emuladores.
