# Manual de RSU Recolección

1. Abre RSU Recolección y elige tu zona. Revisa el distrito si hay nombres similares.
2. Consulta la fecha, el turno y el estado. En ruta indica que el conductor registró la salida.
3. Pulsa **Actualizar** para consultar de inmediato. Con una zona seleccionada, la app consulta cada 30 segundos.
4. Si falla la conexión, revisa la hora de los datos visibles y vuelve a actualizar.

La información se organiza por zona y se muestra en hora de Perú.
